# RepoQL issue report

- Version: exact `rql --version` output (redact local identity)
- Environment: OS/build, native or container, repo and connector ABI versions
- Exact command: redacted command invocation; never paste credentials
- Expected: observable expected result
- Actual: observable result and exit status
- Reproduction: minimal independent steps; version-scope the issue
- Evidence: sanitized logs, timestamps, fingerprints and test output
- Attribution: mark one of RepoQL defect / Harness defect / environment / agent configuration / unconfirmed; state why
- Redaction: no credential, token, secret value, private path or account data may appear in this file

Verify the issue against an isolated source and an independent reproduction before filing. A failure in an unsupported Windows source-only build is not automatically a RepoQL defect.
