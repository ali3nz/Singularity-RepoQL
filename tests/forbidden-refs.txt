# Internal references that must never appear in this repository.
#
# This file is the GENERIC guard: it is committed and runs in public CI, so it
# carries disclosure *shapes* only and never the private inventory itself.
# Site-specific names live in tests/forbidden-refs.local.txt — gitignored,
# present only on the operator's release machine. tests/scan-refs.sh loads that
# overlay when it exists and REQUIRES it when FORBIDDEN_REFS_REQUIRE_LOCAL=1,
# so public CI and the release gate share one scanner with different inputs.
#
# Extended regex, one pattern per line, consumed by tests/scan-refs.sh (grep -E).
# Keep patterns high-signal; when a hit is a false positive, fix the text or
# narrow the pattern here — never delete a pattern without review.

# Private network addresses: RFC1918, link-local and CGNAT ranges
# The trailing ([^/]|$) keeps documented CIDR blocks — 172.16.0.0/12, 10.0.0.0/8 —
# from being reported as private addresses.
\b192\.168\.[0-9]{1,3}\.[0-9]{1,3}\b([^/]|$)
\b10\.[0-9]{1,3}\.[0-9]{1,3}\.[0-9]{1,3}\b([^/]|$)
\b172\.(1[6-9]|2[0-9]|3[01])\.[0-9]{1,3}\.[0-9]{1,3}\b([^/]|$)
\b169\.254\.[0-9]{1,3}\.[0-9]{1,3}\b([^/]|$)

# Absolute paths into a personal home directory or a host-mounted volume
/home/[A-Za-z0-9._-]+/(docker|work|projects)\b([^A-Za-z0-9._-]|$)
/mnt/(backups|newdata|hub)(/|[[:space:]]|$)
/mnt/[A-Za-z0-9._-]+/(backups|newdata|hub)

# Unqualified ticket, programme and run identifiers. References to real
# upstream issues must be qualified — owner/repository#123, a full
# https://github.com/owner/repository/issues/123 URL, or a markdown link whose
# target is validated — so an ambiguous bare number can never ship.
\b[Ii]ssues?[[:space:]]*#?[[:space:]]*[0-9]{2,4}(/[0-9]{2,4})?\b
\bP[0-9]{3,4}\b
\brun[0-9]{2,4}\b
\bkit[[:space:]]+D[0-9]{2}\b

# Credential-manager state that must never be referenced in shipped material
\bkeychain\b
\bBW_SESSION\b
\bbitwarden\b
